# V10.119 · 翻页下层内容连续

基于 V10.118。只修第二页打开时的底部空白，不修改已确认的飞行、到位停稳、按快门或打印时序。

## 原因与修改

- 实际相机画面是宽度 × 1.5；翻页预览层则是整个屏幕高。390×844屏幕上，预览只填了585px，余下259px原来显示为空白纸色，而翻页完成后的真实页面会接上下一章节。
- 新增独立的 `page-continuation.js`：在原预览层内一次性复制主页面现有的后续章节，紧接相机画面。复制层不增加文档高度，不新增章节或更换设计；首段退出时与预览层一起隐藏。
- 复制层 `aria-hidden` / `inert`，去掉重复ID与键盘焦点，真实章节仍是唯一可访问内容。无新滚动事件、逐帧任务或测量。
- 覆盖旧预览层对所有图片强制100%高度的规则；实际和预览中的后续原照使用同一固有宽高，慢加载时也保留位置。图片仍懒加载、镜像低优先级。
- 首屏、相机底图、原照与裁切、角色尺寸/动作、动画时序和往返滚动只播放一次机制不变。四个动画脚本与V10.118逐字节一致。
