# V10.208 — 微信音乐手势重试

基于 V10.207，2026-10-04。历史版本保持不变。

- 把原来仅绑定封面点击的播放恢复，扩展为全页可信 `touchend` / `click`。直接在事件回调里调用 `audio.play()`，不等待异步任务，不拦截默认滚动。
- 自动播放遭拒时显示固定的“开启音乐”按钮；网络失败显示“重试音乐”。成功后收起，不增加纸张高度。
- 排除播放按钮、进度条、进度面板和提示按钮的子元素，防止捕获阶段先启动、按钮自身又立即暂停。
- 手势播放请求未完成时去重。手动暂停/取消后，触摸、滑动和返回前台不会强制开启；歌曲结束也不会被页面触摸重新播放。
- 保留 50 秒初始起点和重播起点，恢复播放/重试保留当前位置。静态音乐、时间轴 1.25 倍节奏、歌词、园林、照片与页面尺寸不变。
- 字体 WOFF2、manifest、字体加载器和时间轴数学脚本与 V10.207 逐字节一致。新提示按钮使用系统字体，不改变手写字体；需要重建手写字库时沿用 V10.207 的构建工具。

## 校验

- `test-music.cjs`：模拟捕获/冒泡事件，验证全页触摸即时重试、明确点击、重复事件、按钮子元素排除、被拦截后提示、手动暂停/取消、后台切换、播放结束、网络重试和迟到 metadata 的 50 秒定位。
- `test_release.py`：7项离线发布测试；限定 HTML 改动，验证字体与时间轴文件完全一致、按钮可访问性/固定布局、新旧音乐脚本替换、96个依赖以及园林题字 SVG 发布回归。
- `test-timeline.cjs`、`test-font-loader.cjs` 及原页面接力测试均保留并运行。
- 本地浏览器曾受 URL 访问策略限制，不使用其他方式绕过。本轮校验为离线解析/模拟 DOM 与 OSS 源站字节校验，不声称微信真机验收。部分微信/iOS 环境可能仍拒绝滑动后的有声播放，此时明确按钮可供用户点击重试；不使用伪造事件或未经验证的 JSBridge 解锁技巧。
