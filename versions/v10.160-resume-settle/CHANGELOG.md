# V10.160 — 修复滑动结束后仍停住

- 基于 V10.159，仅修第三页归位后续播。其他页面、手绘标题、鎏金分隔、图片资源和加载策略不变。
- 根因复现：原归位循环逐帧减小滚动差值，要求误差小于 1px 才继续播放。滚动位置按像素取整时，最后几像素的增量被舍弃，导致循环永不结束。旧模拟测试允许任意精度 scrollTop，没有覆盖此情形。
- 改用 420ms 有限时长、缓出的归位过程；结束后直接设置目标滚动位置并退出归位状态，不再用位置误差阻塞动画进度。归位仍会尊重手动滑动、页面离开和后台暂停。
- 保留手动滚动停止 900ms 后归位、播放完成后不重播的行为。原 19 张照片、时间轴文字、照片飞行动作/顺序不变。

验证：同一整数像素测试中，V10.159 停止打字，而新版继续；覆盖 1/0.5/0.333px 滚动量化、8/16/32ms 帧间隔、正反向滚动、边界钳制和照片阶段续播。原手动暂停、长按、惯性、后台、离开返回、减弱动画、加载失败、单 RAF 及多种页面高度回归全部通过。
