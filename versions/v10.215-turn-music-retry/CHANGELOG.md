# V10.215 · 自动翻页开始时尝试音乐

基于已部署 V10.214。首屏素材就绪时已有自动播放尝试，但实际 3 秒翻页开始时没有单独重试。

- 音乐模块监听现有根节点 `turn-playing` 状态，在真实翻页开始时最多补一次普通播放请求；不另设独立的 3 秒计时器。
- 素材未就绪导致翻页延迟时，音乐也等到实际翻页；用户取消自动翻页、减弱动态效果或深链接跳过封面时，不凭空触发该重试。
- 已经播放、手动暂停、播放结束、音频错误、后台、挂起中的加载或用户播放请求均不被打断。
- 不重新加载音频、不重置进度、不伪造用户点击或微信事件。被平台拒绝时继续显示点击入口。
- 页面 HTML、开场动画脚本、第二页人物 20% 放大、新照片和全部其他页面保持原样。

## 验证

`test-turn-music.cjs` 联合实际自动翻页控制器和音乐脚本，通过模拟时钟检查 2999ms 不重试、3000ms 实际启动翻页时重试一次、延迟素材、取消/后台/减弱动态、重复通知、播放拒绝与手动优先。

音乐、首屏就绪、滑动、照片与资源回归通过。测试使用模拟 DOM/媒体，不是微信真机验收；自动翻页不是用户激活，不能保证微信放行有声自动播放。
