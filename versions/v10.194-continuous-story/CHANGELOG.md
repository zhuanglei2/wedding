# V10.194 — 新第三页接入完整自动滚动流程

- 完整网页使用 V10.193 已压缩手绘区的图片，以及 V10.191 独立歌词图。根目录本地入口更新至本版，旧版本文件保持不变。
- 根因：V10.183 把相机页滚动目的地改成新增 `gathered-scenes`，到达后就结束，没有通往 `celebration` 时间轴的后续步骤；时间轴不在可播放视区，后续流程因此没有触发。
- 现在由同一控制器接管：第二页动画自然完成 → 保持 1 秒 → 1.4 秒进入新第三页 → 等待照片与歌词加载 → 展示 3 秒 → 内容超过一屏时缓慢看至歌词底部并保持 1 秒 → 1.4 秒进入时间轴。短屏内能完整展示的照片页跳过内部滚动。
- 整段过程中保留 `story-handoff-pending`，直到真正到达时间轴才释放并触发原有播放事件，避免两套滚动同时启动。
- 手动触摸/滚轮/键盘、切后台、页面跳转、旋转/缩放、音乐按钮操作会取消自动流程；回看不重播。不把原生异步 scroll 事件误当成用户输入。
- 只在第二页结束后预热新页两张图，不抢首页加载。资源失败/超时和禁用动态效果都有有限退出，保留手动阅读。
