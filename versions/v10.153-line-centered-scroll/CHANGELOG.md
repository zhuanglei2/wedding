# V10.153 — 当前文字行居中跟随

- 在 V10.152 基础上仅修改滚动跟随逻辑，漫画、纸张、图片和文案保持不变。
- 使用实际字符矩形归并文字行，以当前行中心对准时间轴可见窗口中心；开头受到自然滚动边界限制，不增加空白占位。
- 换行、段落与日期切换同步更新目标，取消原来的 74% 下沿触发 / 65% 停靠逻辑及段首 22% 定位。
- 一般换行平滑跟随；较大的跨段跳转先确保当前行不被渐隐边缘遮挡，再平滑归中。
- 字体加载完成、窗口及 visualViewport 尺寸变化时重新测量当前行，节点停顿期间也可重新居中。
- 保留正文每字 45ms、每节点结束后 1000ms 停顿、照片播放节奏与手动滚动接管。
