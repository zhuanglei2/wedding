# V10.200 · 园林照片接入建筑线稿

2026-09-25，基于 V10.199 的已批准方向。

- 照片顶部加入一小段暖纸色屋檐铅笔线稿，用浅斜向、不规则纸边接回实拍，呼应第三页的建筑线稿与照片拼接。
- Imagegen 仅生成独立建筑素材；照片、人物与红色题字全部继续使用 V10.198 文件，未重画、重压缩或修改原照。
- 装饰层高度上限为照片的 21%，蒙版最下缘约为 20.28%；人物保守上界为 24.38%，因此不覆盖头发、脸、衣服或裙摆。
- 红字内容、字号、错位、取景、页面高度和原有底部轻羽化不变；只提高题字的堆叠层级以保持在装饰之上。
- 沿用已有延迟加载和同一个滚动控制器。新素材加入原有等待图片集合，全部加载后仍停留 3 秒；手动操作及加载异常行为不变。
- 新图保留 PNG 母版，网页使用逐像素相同的无损 WebP。完整提示词与来源见 `design/generation.md`。
- 保留旧版本和独立实验页。仅本地更新，未部署 OSS、未提交 Git。
