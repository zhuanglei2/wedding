# V10.62 · 星星人牵引纸页

基于 V10.61，首屏点击入口不变。仅本地预览，不部署。

## 连贯动作（约 4.6 秒）

1. 0–1.1 秒：两位角色错开飞来，手臂摆动、男角色蹬腿。
2. 1.1–1.7 秒：减速、伸出右手握住纸边；纸张尚未整体翻动。
3. 1.7–3.6 秒：身体后仰，手抓点跟随同一纸边；纸张分段弯曲、翻过去，露出第二页。
4. 3.6–4.6 秒：松手、收臂，两位角色带星光离开，第二页留在原位。

## 实现边界

- 使用生成的角色分层素材做 2D 关节动画，不是逐帧生成视频或完整 3D 模型。
- 双臂独立旋转，男角色双腿独立运动；身躯姿态与纸张受力同步。
- 图片、文字、真实新人不重绘；纸张使用原请柬贴图，12 段连续投影。
- 确定性动作计算沿用原生网页驱动，不引入视频框架。采用 HyperFrames 抓取同步与有限动作规则。
- 不新增开屏、按钮文案或音效。减少动态效果、资源缺失时保留原生页面导航。
- 生成图片原件为 rig-atlas-original.png，完整提示词记录于 rig-prompt.txt；内置 imagegen 生成。用户确认后使用 matte-rig.py 本地去底，rig-atlas.png 保留源 RGB 与尺寸，只添加透明遮罩。
