# Wedding website versions

- **v1.0 — Editorial storybook**: baseline redesign. A vertically paced wedding website with an unedited studio-photo hero and one independent chapter for each photo.
- **v1.1 — Refined name lettering**: same layout and photos as v1.0; only the homepage names use a calmer handwritten type treatment.
- **v1.2 — Calligraphic names**: same layout and photos as v1.0; the homepage names use an upright, brush-like handwritten style.
- **v1.3 — Festive welcome**: same layout and photos as v1.2; the homepage header adds a restrained red-and-gold wedding celebration treatment.

To roll back the public entry page, point ../../index.html to the desired version folder. New visual changes should be created as a new vX.Y folder; never overwrite an existing version.

Use versions/index.html in a browser to switch versions and read the change log.
