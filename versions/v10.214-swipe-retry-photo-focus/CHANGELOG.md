# V10.214 · 滑动重试与第二页人物放大

基于本地 V10.213；保留 V10.212 的新婚纱原照与所有页面设计。

## 修改

- 第二页照片在原相框内部显示放大 20%，变换中心为 45% / 62%，减少两侧与上方背景；原 JPEG 不重新生成、压缩或重采样。
- 主页面、翻页底层和吐片弯曲条带使用同一个裁切规则，纸张与动画坐标不变。
- 修复上一条触摸结束后 `play()` Promise 一直挂起，导致之后全部触摸被 `gesturePending` 去重标记拦住的问题。每次新的有效单指触摸可重新请求，仍在该真实事件回调内调用 `play()`。
- 触摸取消只清理去重标记，不启动音乐。不在滚动、移动或定时器里循环重试；已经播放和手动暂停的状态仍优先。
- 保留 V10.213 微信真实就绪/首次交互不等待图片的修正。普通非交互尝试仍等首屏素材，音乐仍从 50 秒开始。

## 验证

旧版模拟复现：第一次滑动累计 2 次播放请求后，第二次滑动仍停留在 2 次。新版累计 4 次，不重载音源或重置进度；被平台拒绝时仍显示点击入口。

`test-swipe-focus.cjs` 覆盖连续挂起请求、取消、重复释放事件、真实点击恢复、手动暂停、正在播放不重启，以及按照片尺寸和相框比例计算的两个人头部安全裁切。该裁切检查不是浏览器截图验收。

音乐、首屏就绪、资源和照片一致性检查通过，页面 HTML 除新增局部裁切样式链接外不变。95 个资源可解析。
