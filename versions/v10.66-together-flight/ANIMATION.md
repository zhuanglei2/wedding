# V10.66 · 男孩等待女孩，再一起飞走

基于 V10.65，保留请柬与角色素材，缩小人物 15%，调整纸面与播放机制。仅本地预览，不部署。

修正：纸片使用负 rotateY，右缘进入朝向观看者的正 Z 空间；握持点跟随新的透视投影，人物轻微靠近。左侧书脊仍固定，不镜像请柬或真人照片。正面掀起高光及背面阴影随纸片朝向变化。

## 连贯动作（约 4.5 秒，另有最多 0.25 秒首屏定位）

1. 0–1.1 秒：两位角色错开沿弧线飞入，减速接近右侧纸边。
2. 1.1–1.5 秒：伸手握住纸边，短暂蓄力；纸张保持静止。
3. 1.5–2.9 秒：身体后仰拉动，手部接触点跟随纸边透视，先后松手。
4. 2.7–3.6 秒：男角色先向会合点飞去，从约 3.2 秒开始悬停，等待女角色靠近。
5. 3.6–4.5 秒：两人使用同一轨迹增量、同一节奏向右上方飞离，保持两人之间的距离；纸张完成翻页。

点击首屏或向下滚动越过翻页起点后自动播完整段，不再按手指位置逐帧控制。播放期间暂时接管单指滚动，结束后恢复；按 Escape 可跳过，切后台/转屏也会收尾。返回请柬可重新播放。手机地址栏高度变化不重启动画。

## 实现边界

- 使用生成的角色分层素材做 2D 关节动画，不是逐帧生成视频或完整 3D 模型。
- 双臂独立旋转，男角色双腿独立运动；身躯姿态与纸张受力同步。
- 图片、文字、真实新人不重绘；纸张使用原请柬贴图，24 段连续投影，背面共享完整渐变。
- 确定性动作计算沿用原生网页驱动，不引入视频框架。采用 HyperFrames 抓取同步、蓄力与释放动作规则。
- 静态与模拟运行测试通过，并检查了实际角色绘制器的六个分段姿势图；尚未进行浏览器交互或真机视觉验收。
- 不新增开屏、按钮文案或音效。减少动态效果、资源缺失时保留原生页面导航。
- 生成图片原件为 rig-atlas-original.png，完整提示词记录于 rig-prompt.txt；内置 imagegen 生成。用户确认后使用 matte-rig.py 本地去底，rig-atlas.png 保留源 RGB 与尺寸，只添加透明遮罩。
