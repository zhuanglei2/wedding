# V10.113 · 快门闪光与照片放大

基于 V10.112；用户确认「打印完成后放大替换相机区域，保留标题，文字等放大结束后再出现」。旧版本未修改，未部署、未推送。

## 动作顺序

时间从第二页角色接棒起计，首屏翻页仍沿用 3800ms。

| 时间 | 动作 |
| --- | --- |
| 1520–1850ms | 镜头单次亮起，先于页面闪光 |
| 1600–1890ms | 一次暖白闪光，峰值透明度0.48（上一版0.16）；不反复闪烁 |
| 1800–3800ms | 原照片从相机吐出，既有打印取景不改 |
| 3800–4050ms | 完整小相片短暂停留 |
| 4050–5350ms | 同一相片层等比放大2.18倍，上移8.15%海报高度；相机渐隐 |
| 5500–6300ms | Record of happiness / 记录幸福渐显 |
| 5800–6650ms | 姓名与日期渐显 |
| 6800ms | 保持大照片最终状态，不切回相机 |

既有牵手离场继续按V10.112的角色节奏进行。新的放大动作发生在角色离场后半段；不改角色体型、衣服或第一屏。

## 视觉与资源

- 统一缩放包含原照和蓝色手绘相纸边，保留同一DOM相片，避免跳切或脸部变形。
- 相纸最终范围约为横向13.44%–87.56%、纵向43.37%–73.23%；上方标题与76%起的文案区不被遮挡。
- 相机淡出时用既有camera-clean.png下方空白纸纹区域作底，不新增生成图，不给真实照片做AI编辑。
- 原照SHA256仍为 `39e6248100d2e1b8eb3ca2cc39af61c0799f76d3211192e31fb3efa7a072040a`。
- 复用V10.112角色/翻页程序和清底图片、V10.111相机版面、V10.106原照；没有增加图片下载资源。
- 减少动态效果、无JS或中途退出时直接保持大相片和完整文字；无闪光。重播会恢复到未打印状态。
