## 已确认的顺序

1. 2024年3月 → 2024年5月 → 2024年7月 → 2024～2026：日期和正文逐字展示，一个节点写完才展示下一个。
2. 最后正文全部写完，原先前十张生活照由慢到快叠落到该正文上方；旧版独立爱心照片从此列表移除。

4. 纪念卡落定后停留 3 秒，整叠照片用 1.2 秒淡出。
5. 继续逐字显示「2026年10月」「我们要结婚啦」，文字结束后渐显本次第六张婚纱照，作为终态。

完整默认流程约 48 秒。输入手势停止自动跟随，后台暂停；单次访问不自动重播。保留未显示节点的布局以避免出现时挤压、跳动。减少动态效果时直接展示完整时间轴与最终照片。无 WAAPI 时仍按相同顺序展示；婚纱照请求失败可点击重试。
