# V10.176 · 快门响起时播放音乐

- 基于 V10.175，改为相机按下快门、闪光开始的动画帧触发音乐，仍从歌曲 18 秒起播。
- 快门通知来自动画自身的 FLASH_START，不增加独立倒计时；每次页面进入只触发一次。
- 保留先图片/角色素材、后音乐的加载顺序，原 192 kbps 音源和页面外观均不变。
- 打印、照片放大、自动翻页仍独立运行，不等待音乐请求成功。
- 暂停后不会因为重复快门通知、照片打印完成或滚动而重播；取消/减弱动画时仍有照片显现的兜底。
- 自动播放被浏览器限制或网络缓冲不足时可能延迟出声，保留手动按钮；实际微信播放未验证。
- 旧版保留，仅本地预览，未部署。
