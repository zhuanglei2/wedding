# V10.148 — 故事自动阅读与照片落纸

基于 V10.147。末节点日期调整为「2024～2026」，正文保持不变。

- 故事线进入视口后，按段落向下自动阅读，文字从下方向上移动。
- 手势、方向键或切换后台中断自动阅读，不锁定页面、不强制回滚。
- 最后文字展示完后，11 张生活照片依次落纸、微回弹、错落叠放；间隔由 880ms 缩短到 180ms，整段约 5.7 秒。
- 每次页面加载只播放一次；减少动态效果偏好下展示静态照片叠放。
- 照片接近故事区时按两个并发加载，不参与首屏资源竞争。
- 原图未改动。WebP 长边不超过 800px，质量 78。11 张总计 540,800 字节（约 528KiB），比输入约减少 76%。

文件：memory.js 为交互控制；memory-math.js 为节奏/位置；memory.css 为相纸样式；optimize.cjs 为图片压缩脚本。

验证：JS 语法、11 张资源存在与单图体积、日期替换、间隔及飞行时长递减检查通过。尚未完成真实手机视觉验收。未部署 OSS。
