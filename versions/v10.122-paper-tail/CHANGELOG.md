# V10.122 · 纸纹延续到页底

基于 V10.121（bbf7dff），修复用户截图中姓名、日期下方纹理渐渐消失、底部出现纯色白带的问题。

- 移除第二页底部向纯色背景淡出的旧效果。
- 仅用现有 camera-clean.png 最下方无图案纸纹延续页底；不生成、裁写或压缩图片。
- 背景接缝使用短距离透明度过渡，保留纸纹；长屏下采样也限定在源图底部四分之一，不会把相机或文字带进来。
- 延续层只负责绘制，不占布局空间；姓名、日期、文案、照片、相机与页面高度保持不变。
- 翻页底层与实际第二页都使用同样处理，所有已有动画脚本保持不变。
- 复用已存在的图片请求，首屏显示前不发起该背景请求。
