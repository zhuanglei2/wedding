# V10.60 · 香槟金星光拖尾

- 基于 V10.59，仅增加五角星与光点组成的飞行拖尾，未改变人物造型、位移路径、请柬成图、照片或文字。
- 两个人物脚后方各有发射点，跟随身体整体转角；浅金五角星与细碎光点沿经过的位置留下短尾，缓慢漂散，640–880ms 内消失。
- 限制最多 36 个粒子，停止运动不再产生，全部消散后停止刷新。画布像素总量约不超过 180 万，最高 1.75 倍像素密度。
- 初次进入仍是静态请柬；只在第一、二页翻页期间触发。点击末尾「翻开我们的故事」可看约 2.6 秒的转场。
- 减少动态效果、页面隐藏、图片加载失败时清理拖尾；无 Canvas 支持则保留原翻页，不阻断内容。
- 目前人物仍是整张双人透明抠图的位移动画；手脚、表情、伸手动作尚未制作。本次拖尾不等同于角色自身动画。
- 使用 HyperFrames 有限粒子与明确消散规则，适配已有原生网页滚动逻辑；Sites 技能用于保留原站结构与本地交付范围。不引入视频框架、外部依赖或新图片。
- 通过 validate.py、test-page-turn.cjs、test-star-trail.cjs；没有进行浏览器交互或真机视觉验收。
- 独立本地版本，未部署 OSS、未推送 GitHub。V10.59 原文件保留，可直接打开上一版本回撤。
