# V10.70 · 侧头、表情与全身跟随

基于 V10.69 新建，旧版本原样保留。仅本地，不部署 OSS、不推送远端、不改首页入口。

## 本次完整动作

保留原有飞入、抓纸、向外拉纸、男孩等候女孩、牵手与星星拖尾。整体时长改为 5.6 秒，另有最多 0.25 秒首屏定位。

- 视线与侧头先于伸手：男孩在约 3.6 秒转向女孩，女孩约 3.8 秒开始回应。
- 新增 12 个生成的头部姿态：两个人物各有正面、向右、向左，以及对应的闭眼表情。三分之四朝向来自素材，不再只移动原图虹膜。
- 借短眨眼切换朝向，取消重叠淡化头像，避免出现两张脸和半透明脑袋。头部的倾斜、点头、抬头连续采样；仍是 2D 多姿态动画，不宣称完整 3D 转头。
- 身体侧倾、躯干小幅转向，双臂有弯曲，男孩腿部带延迟；袖口末端的接触点保持不变。
- 衣摆只从腰以下做连续切变，随起飞加速稍晚跟上。没有循环整身缩放，也没有数十条半透明叠加带导致的横纹。
- 约 4.42 秒牵手，停留约 0.34 秒，再共同向右上方飞离。一个共享接触点约束双方的手。
- 加了肩颈原图毛绒衔接，花束遮罩保留上方花瓣，避免头部移动露出底色或方形贴片。

## 素材与显示

`head-expressions.png` 为内置 imagegen 生成，具体提示词见 `head-prompt.md`。真人照片、请柬、原角色图集、纸张与后续页面均未改写。

图像服务两次均返回了不带透明通道的棋盘格底图，未把它当成真正透明素材发布。采用 `head-masks.js` 的逐姿态几何显示裁剪，原 PNG 不改写。`measure-head-masks.cjs` 只读取像素分析轮廓，输出 JSON 坐标；运行时不读取像素、不要求跨域 canvas 权限。12 组显示轮廓已随版本保存，不依赖生成服务。

## 验证边界

- `test-expressions.cjs` 使用真实画布绘制器检查侧头、闭眼、躯干、衣摆及手机尺寸下的独立角色姿势；输出在 `/private/tmp/wedding-v1070-expression-check.png` 和 `/private/tmp/wedding-v1070-mobile-poses.png`。
- `test-page-turn.cjs` 检查 320–1000 宽度下的纸张受力、持续牵手、首屏无留白、完整播放、点击与滚动、资源未加载或错误时的原生导航、转屏和切后台收尾、减少动态效果。
- `test-paper-surface.cjs` 与 `test-star-trail.cjs` 保留原纸张和有限粒子回归检查。
- `validate.py` 验证真实照片哈希、请柬内容、既有图片不变和新增资源路径有效。
- 未做浏览器交互或手机真机视觉验收；孤立姿势检查不等于手机完整动画流畅度验收。
