# V10.207 — 时间轴提速与手写字体子集

基于 V10.206，保留历史版本及完整字体文件。

- 时间轴打字、段内间隔及照片叠放采用原来的 80% 时长（1.25 倍速度）。正文汉字从 30ms/字改为 24ms/字。
- 每个时间节点结束仍停留 1000ms；四宫格停留 3000ms、淡出 1200ms 不变。实际页面完整时间轴计划从 32.554 秒缩短至 28.463 秒；滚动接力的额外停顿不计入此计划。
- 马善政手写字体从 5,857,936 字节精简为 189,936 字节 WOFF2，减少 96.76%。包含整页静态文字、无障碍标签、漫画对白、动态重试提示和 ASCII，共 530 个受原字体支持的码位。
- 逐字验证轮廓、字宽、边距、hinting 和行高相关度量不变，保留原版权及许可；原字体本来不含的符号继续走原回退字体。
- 保留延后加载、`AboutHand` 字族和字体就绪后的时间轴重排事件。发布包不再引用完整版马善政字体。
- 保留 50 秒音乐起点、歌词、园林题字和纸张、照片与版式、内层滚动跟随及手动暂停逻辑；不启用 V10.205 草稿。

## 校验

- `build-font.py --check`：当前文案覆盖、原字形/度量/hinting/版权一致性、字库和 manifest 哈希一致。
- `test-font-loader.cjs`：按需加载、单次请求、字族参数及重排事件。
- `test-timeline.cjs`：新旧事件顺序一致、1秒停顿、19张照片、四宫格与最终照片顺序、固定漫画/纸张、遮罩安全区、跟随、手动干预、降级和异常图片。
- `test-music.cjs`：50秒首播和重播、自动播放回退、后台恢复、迟到 metadata 及拖动。
- `test_release.py`：发布路径、全部资源、JS 语法、旧 SVG 引号损坏回归、园林4组题字属性、与 V10.206 的严格改动边界。
- 浏览器工具曾受 URL 策略限制，本轮不声称完成微信真机或视觉/FPS 验收；上述为离线解析、字体与模拟 DOM 测试。

字体重建需要独立环境中的 `fonttools[woff]==4.66.0`，不改网站项目依赖。文案更新后重跑 `build-font.py`，再运行 `--check`。发布仅执行显式 `publish.py --deploy`，凭据只保留在进程内存。
