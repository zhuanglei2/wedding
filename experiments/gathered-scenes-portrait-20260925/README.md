# Still, together. — 独立页面预览

按用户指定的 scenes-gathered-zine-v1-3 技能设计。初次 AI 海报改变了人像，经用户指出后，改为原始照片与外围网页装饰分层。

- 真人摄影是主视觉，宫廷拱形与墙面直线延展成稀疏插画和朱红色印刷结构。
- `portrait-original.jpg` 是用户原图的逐字节副本，人物不经生成、重绘或滤镜；页面只对周边背景做取景，完整人像与裙摆留在范围内。
- `index.html` 为独立静态页面，手机按屏宽显示，桌面适配屏高；无外部依赖、脚本或追踪。
- 之前的 `poster.png` / `poster.webp` 不是最终人物画面。只取其无人物的纸纹及拱线区域作装饰，所有生成的人像均排除在可见区域之外。
- `tear-mask.svg` 只作用于照片周边的纸张边界，不改变人物像素。
- 用户原始文件未改写；本地副本未提交。既有请柬未修改；本页未部署 OSS。
