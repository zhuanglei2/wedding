## 去背景试验

`matte-test.cjs` 使用同一类边界连通算法、两档米色容差28和85。它不是专业视频语义分割或人工逐帧蒙版。两者都把相近的米色背景与白色服装混淆；保守参数也留下纸张折痕。

全帧运行只证明算法执行完整，不等于全帧视觉验收或蒙版准确度。`matte-metrics.json` 的像素数量不是准确率，没有用它声称可用。`diagnostic-comparison.mp4` 是97帧的原片/保守去背景并排对照，1152×1064、24fps、4.041667秒；已通过完整解码验证。原片水印保留，所有产物仅用于诊断。

不能由这两次失败推论所有抠像工具均不可行；但足以否定目前“普通去色后直接叠HTML”的方案。下一步必须先验证视频人物分割/人工蒙版及掌边跟踪，不能仅靠换提示词或宣称MP4透明解决。

## 重现

脚本均只读原MP4并写入指定的测试目录：

1. `node extract.cjs <ffmpeg可执行路径> <输入mp4> <临时帧目录>`
2. `node contact.cjs <临时帧目录>`
3. `node matte-test.cjs <临时帧目录>`
4. `node contact-gap.cjs <临时帧目录>`
5. `ffmpeg -framerate 24 -i <临时帧目录>/compare-frames/frame-%03d.png -c:v libx264 -crf 20 -pix_fmt yuv420p -movflags +faststart diagnostic-comparison.mp4`
