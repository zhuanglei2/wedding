# V10.77 · 抓纸与拉动关键动作

这是可播放的 5 秒、20fps 动图，不是上一版的静态拼图。范围只包括靠近伸手、贴住纸边、后倾蓄力、向左拉出曲面、停留检查；没有等待、牵手或飞走。

## 二维、2.5D 与三维

- V10.76 是静态离线合成对照，人物是整张二维贴图。
- V10.77 使用 V10.71 现有分层图集，手臂/肘部与腿部实际运动；完整头颈/领口作为一个连接层。纸面使用带 z 深度和不同法线的曲面投影。
- 因为人物仍是二维图集，不是立体角色模型，所以本片只能称为 2.5D，不是完整三维动画。GIF/MP4 是文件容器，本身不决定内容是二维还是三维。
- 图集是历史 AI 参考衍生素材，来源见 V10.71 的 ASSET-SOURCE.md，不等同于原产品照片。此轮没有重绘、换脸或改写任何原素材。

## 接触检查与限制

手掌接触位置与纸边使用同一坐标。身体后倾、脊柱角度与手臂抬起后，重新求解角色位置，使渲染出来的手仍停在该抓点，并检查抓点附近存在不透明手掌像素。

这不等同于真实手指抓握：现有素材的手是毛绒掌，没有独立手指。无法表现细致的握紧/松开或手指包住纸背。此样片只验证贴边、蓄力、持续拉动的关系。

纸面是受控曲面投影，不是物理纸张模拟；添加简化边缘明暗，不代表最终纸质光影。人物仍可能有二维木偶感，不把坐标测试通过当作审美达标。

原请柬和第二层照片使用原文件。动图有调色板量化，仅作动作预览，不用作线上清晰请柬。手机实际播放、滚动映射与完整转场未验证。
