# 中式诗经双人影集

本页按用户最新提供的中式长页参考设计，不使用上一轮 OMM 的上下 50/50 形式。两张指定原片在同一个滚动页面中展示；没有婚礼请柬标题、英文邀请语、时间、地点或表单。

## 固定纸张修订

改为固定单页排版，不再由内容撑成长页。独立预览使用现有请柬 `syncPaper()` 的回退尺寸规则：`max(视口高度, 纸宽 × 1.5)`；正式接入时应直接读取上一张纸的实际高度。两张完整照片左右错位，一大一小，诗句放在空白处。没有通过截断整页来隐藏内容。

- 原照未经生成模型处理。只输出 WebP 网页资源，原始文件保持不变。
- 第二张源文件为带上下黑边的截图。网页仅隐藏 0–128 和 1014–1279 行，完整保留摄影区域 129–1013；资产本身也保留黑边。
- 沿用第二页原始纸纹 `versions/v10.125-keepsake-fast/media/camera-clean.webp` 的底部空白区域，以 100% 页面宽度、8:3 交替翻转平铺。
- 装饰为独立绘制的本地 SVG：苔绿植物暗纹与朱红小花。参考图只用于版式与配色参考，没有复制参考中的照片、姓名或图案资产。
- 诗句更新为：今夕何夕，见此良人。上下两处留白各排半句。
- 出处：[《诗经·唐风·绸缪》](https://ctext.org/text.pl?if=gb&node=14950&remap=gb&show=parallel)，仅存于本开发记录，页面不显示出处。
- 按要求删除姓名、页眉小标题、照片说明、图片序号和出处链接。图片的无障碍替代说明保留，不显示在正常画面中。
- 浏览器视觉验收尚未进行；静态检查不代表截图验收。

独立预览，没有替换请柬或部署。

照片装裱修订：添加窄暖白相纸边、细内框、柔和落影和 ±0.4° 的轻微错位。增大外框宽度以补偿边框占用，不明显缩小照片。处理只作用于网页装裱，不给人像加滤镜、不修改图片资源，单页高度不变。
