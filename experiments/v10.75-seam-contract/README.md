## 怎么看

本地打开 index.html，拖动时间滑块或点阶段按钮。圆框标人物空间、金色点标手的目标接触点。可关闭辅助线检查原始首尾素材。

这是手动取样的技术检查工具，不是 HyperFrames 成片、不自动播放、不渲染角色肢体或粒子。真实星星人的自然动作仍需视频样片验收。

检查页以完整请柬的高度进行材质对照；现有网页的第二层实际以浏览器可视高度显示，因此本页只能确认素材来源、完整比例与几何路径，不等于手机首尾帧已经无缝。最终需冻结触发时视口尺寸和滚动偏移，用同一坐标映射驱动纸面与角色。不能强制缩小整张请柬塞进一屏。

## 动作节奏（以观众视角定义左右）

| 时间 | 内容 |
|---|---|
| 0–1.0 秒 | 角色短弧靠近右侧自由边，少量星尾 |
| 1.0–1.6 秒 | 先看抓点、抓紧，再弯肘蓄力；星尾减弱 |
| 1.6–4.0 秒 | 同时拉向左侧，手跟随两个抓点；纸向镜头轻弯 |
| 4.0–5.2 秒 | 在画内松手，继续惯性并转弯，男孩先到会合点 |
| 5.2–5.8 秒 | 男孩看向女孩并悬停等待，女孩从较低路线靠近 |
| 5.8–6.4 秒 | 男孩在画面左、女孩在画面右，相邻的两只手伸出并相接 |
| 6.4–7.4 秒 | 牵稳手后相视停留 1 秒，不急着离开 |
| 7.4–9.2 秒 | 保持一个共同牵手点，一起向右上方飞走 |
| 9.2–10.0 秒 | 不再产生新星，剩余金星渐隐，露出真实第二页素材 |

时间是导演目标，不是模型的逐帧执行承诺。10 秒是否可选、费用与余额均未重新核实；不能按旧价格自行扣费。

## 生成与合成方案：不能跳过的验证

- 保留用户要求的完整“抓纸—拉开—等待—牵手—共同飞走”视频动作，不改成只有角色漂浮的素材。
- VIDEO-PROMPT.md 改为带操作安全区的完整动作稿；旧 V10.74 首帧不能直接搭配这条新提示词。
- 用无真人照片/无真实文字的纸面动作底板测试模型；真实网页图永远由本地原图提供。未确认允许前，不把真人婚纱照上传生成平台。
- 对生成结果需要角色遮罩及纸面变形跟踪，才能替换成原请柬并显露真实下层。普通不透明 MP4 不是可直接覆盖的透明层；本版没有实现、没有假定生成工具能导出这些层。
- 即便主色与画幅一致，也不能用“原请柬→空白红纸视频→真实照片”的硬切当成完成。
- 只有角色与纸的遮挡/抓点跟踪可恢复、服饰完整、手部可信、手机播放与滚动通过，才可接入。否则报告无法可靠合成，不用突然淡出掩盖。
- 下一步应先确认可获得的输出是否支持可靠分层，准备符合此坐标的角色首帧，再重新核对平台时长与实际价格。不是现在点击生成。
